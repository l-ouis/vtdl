Tags

Inline code blocks in your notes:

persist
Entire group is carried across days.
expiry:n
Auto-stamps checked lines in the group with expires:n.
expires:n
Hidden: decrements daily and disappears at 0.
repeat:n,r
Hidden: auto-unchecks n days after being checked.
newtab
Hidden: ends a tab; always persists across days.

Global shortcut compatibility

Windows · macOS · Linux X11

Just record a keycombo, untested though.

Linux Wayland

Bind your shortcut in Settings → Keyboard → Custom Shortcuts to:

/path/to/vtdl --toggle

vtdl is single-instance, so the same command launches it on first call and toggles show/hide on later calls. To keep the toggle reliable, dismiss the window with soft-close rather than minimizing.
